Coloque o teste no seu site

O Roda o VI é aberto. Copie as duas linhas abaixo e o teste aparece no seu site, em português, inglês ou espanhol. Nada é baixado no PC de quem usa.

1. Widget pronto

<script type="module" src="https://roda-o-vi.netlify.app/embed/rodavi-widget.js"></script>
<roda-vi-teste idioma="pt"></roda-vi-teste>

Pra mudar as cores, use variáveis de CSS no seu site:

roda-vi-teste {
  --rodavi-fundo: #ffffff;
  --rodavi-texto: #14151C;
  --rodavi-mudo: #5C6070;
  --rodavi-borda: #E2E4EA;
  --rodavi-trilho: #E6E7EC;
  --rodavi-campo: #F4F5F8;
  --rodavi-raio: 16px;
}

O widget avisa quando tem resultado:

document.addEventListener("rodavi:resultado", (e) => {
  console.log(e.detail.pct, e.detail.port.titulo);
});

2. Só o motor de cálculo

Monte sua própria tela usando o mesmo cálculo do site.

import { carregarDados, detectarGPU, acharGPU, avaliar }
  from "https://roda-o-vi.netlify.app/lib/rodavi.js";

const { gpus, cpus } = await carregarDados();
const gpu = acharGPU(detectarGPU(), gpus);
const r = avaliar({ gpu, cpu: cpus[0], ramGB: 32, idioma: "pt" });
// r.pct, r.fps.min, r.fps.max, r.etapa, r.port.titulo ...
